# Training

A read-only strength training reference for Claude: exercises, muscles worked, setup and execution steps, common mistakes, safety notes, home or gym substitutions, and equipment.

- Remote MCP server: https://mcp.arnoldtrainingapp.com/claude/mcp (no login, no personal data stored)
- Documentation: https://mcp.arnoldtrainingapp.com/docs-training
- Support: https://arnoldtrainingapp.com/support
- Privacy: https://arnoldtrainingapp.com/privacy

General reference only; it does not give personal or medical advice.

## Install

In Claude Code, from a marketplace that lists this plugin:

```
/plugin install training --marketplace 1genadam/training-plugin
```
